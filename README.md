# deneyrehberin.github.io
Lise ve üniversite öğrencileri için simülasyon, deney videosu ve öğrenme kaynağı rehberi. Öğrenci seviyesini, dersini ve konusunu seçer; konuyla ilgili simülasyonlar ve videolar, sitelerin adı ve açıklamasıyla birlikte listelenir. Böylece öğrenci bağlantıya tıklamadan önce hangi kaynağı seçeceğine karar verebilir.
